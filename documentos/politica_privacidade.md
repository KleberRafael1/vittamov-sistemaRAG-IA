## 1. Apresentação

A Clínica VittaMov valoriza a privacidade e a proteção dos dados pessoais de seus pacientes, colaboradores, profissionais e demais pessoas que utilizam seus canais de atendimento.

Esta Política de Privacidade apresenta, de forma geral, como a Clínica VittaMov coleta, utiliza, armazena e protege informações pessoais durante suas atividades.

O tratamento de dados pessoais realizado pela clínica deve observar a legislação brasileira aplicável, especialmente a **Lei Geral de Proteção de Dados Pessoais — Lei nº 13.709/2018 (LGPD)**.

# 3. O que são Dados Pessoais?

Dados pessoais são informações relacionadas a uma pessoa natural identificada ou identificável.

Exemplos de dados pessoais que podem ser utilizados pela clínica:

* nome completo;
* CPF;
* data de nascimento;
* telefone;
* endereço;
* endereço de e-mail;
* informações de cadastro;
* informações relacionadas ao convênio;
* informações necessárias para faturamento;
* dados relacionados ao agendamento.

---

# 4. Dados Pessoais Sensíveis

Algumas informações relacionadas aos pacientes podem ser classificadas como **dados pessoais sensíveis** pela LGPD.

No contexto de uma clínica de saúde, podem existir dados relacionados à saúde do paciente, além de outras informações protegidas pela legislação.

Exemplos:

* histórico de saúde;
* informações sobre lesões;
* diagnósticos apresentados pelo paciente;
* informações sobre procedimentos;
* exames;
* relatórios médicos;
* informações relacionadas ao tratamento.

A clínica deve adotar medidas apropriadas para proteger essas informações.

# 5. Quais Dados Podem Ser Coletados?

Dependendo da finalidade do atendimento, a clínica poderá coletar diferentes categorias de informações.

### Dados cadastrais

* nome;
* CPF;
* data de nascimento;
* telefone;
* e-mail;
* endereço.

### Dados relacionados ao atendimento

* serviço agendado;
* profissional responsável;
* histórico informado pelo paciente;
* informações relevantes para o atendimento;
* documentos apresentados;
* exames e relatórios, quando necessários.

### Dados relacionados a convênios

* nome da operadora;
* número da carteirinha;
* informações necessárias para autorização;
* dados relacionados ao procedimento autorizado.

### Dados financeiros

Quando necessário para pagamento ou faturamento:

* forma de pagamento;
* informações relacionadas à transação;
* dados necessários para emissão de nota fiscal.

A clínica não deve coletar dados além daqueles necessários para as finalidades relacionadas às suas atividades.

# 7. Dados de Saúde

Informações relacionadas à saúde possuem proteção especial pela legislação brasileira.

A Clínica VittaMov deve limitar o acesso a essas informações às pessoas que necessitem delas para desempenhar suas funções.

Dados de saúde não devem ser utilizados para finalidades incompatíveis com aquelas relacionadas ao atendimento, às obrigações legais ou às demais hipóteses permitidas pela legislação.

# 8. Compartilhamento de Dados

A Clínica VittaMov poderá compartilhar determinados dados pessoais quando necessário para executar suas atividades ou cumprir obrigações legais.

Possíveis situações incluem:

* operadoras de planos de saúde;
* profissionais responsáveis pelo atendimento;
* empresas responsáveis por serviços administrativos;
* empresas de tecnologia utilizadas pela clínica;
* empresas responsáveis por processamento de pagamentos;
* autoridades públicas quando houver obrigação legal.

O compartilhamento deve ser limitado às informações necessárias para a finalidade correspondente.

---

# 9. Compartilhamento com Convênios

Quando o paciente utiliza um plano de saúde, determinadas informações podem precisar ser compartilhadas com a operadora para:

* verificar elegibilidade;
* solicitar autorização;
* registrar procedimentos;
* realizar faturamento;
* cumprir exigências administrativas e regulatórias.

O compartilhamento deve observar as regras aplicáveis à proteção de dados pessoais.

---

# 10. Compartilhamento com Profissionais de Saúde

Informações necessárias ao atendimento podem ser acessadas pelos profissionais responsáveis pelo acompanhamento do paciente.

O acesso deve respeitar os princípios de necessidade, segurança e confidencialidade.

Profissionais não envolvidos no atendimento não devem acessar informações de pacientes sem justificativa adequada.

# 11. Uso de Dados pelo Agente Virtual

A Clínica VittaMov utiliza um agente virtual como ferramenta de atendimento e consulta à base de conhecimento institucional.

O agente virtual pode fornecer informações gerais sobre:

* serviços;
* horários;

* cancelamento;

# 12. Limitações do Agente Virtual

O agente virtual **não deve solicitar, armazenar ou interpretar informações clínicas desnecessárias** para responder dúvidas administrativas.

O agente não deve:

* realizar diagnóstico;
* interpretar exames;
* prescrever medicamentos;
* prescrever exercícios;
* definir tratamento;
* substituir profissionais de saúde;
* informar dados de outros pacientes;
* divulgar informações confidenciais;
* inventar informações sobre pacientes.

Quando uma pergunta exigir acesso a informações clínicas individuais, o usuário deve ser encaminhado para os canais apropriados da clínica.

---

# 13. Informações de Outros Pacientes

O agente virtual não deve fornecer informações pessoais ou clínicas de outros pacientes.

Exemplos de informações que não devem ser divulgadas:

* nome de pacientes;
* telefone;

* diagnóstico;
* histórico médico;
* resultados de exames;
* tratamentos;
* horários de consultas;
* informações financeiras.

Mesmo que um usuário solicite essas informações, o agente deve negar o acesso e orientar a utilização dos canais oficiais quando necessário.

# 15. Controle de Acesso

O acesso aos dados deve ser concedido de acordo com a necessidade de cada função.

Por exemplo:

* equipe administrativa pode acessar informações necessárias ao agendamento;
* equipe financeira pode acessar informações necessárias para pagamentos e faturamento;
* profissionais de saúde podem acessar informações necessárias ao atendimento;
* usuários externos não possuem acesso aos dados internos dos pacientes.

O princípio do menor privilégio deve ser considerado na definição dos acessos.

# 26. Agente Virtual e Alucinação

O agente virtual deve utilizar exclusivamente informações presentes em sua base de conhecimento ou em sistemas autorizados.

Quando não encontrar uma informação, deve informar claramente que não possui dados suficientes para responder.

O agente não deve criar:

* dados de pacientes;
* diagnósticos;
* valores;
* horários;
* informações de convênios;
* informações jurídicas;
* políticas inexistentes;
* informações sobre tratamentos individuais.

A ausência de informação deve resultar em uma resposta transparente, e não em uma informação inventada.
